Android App Links (assetlinks.json)
For Android to auto-open your app (instead of showing "Open with…" chooser), you must host an assetlinks.json file on your server. AppForge generates the file and injects autoVerify="true" into AndroidManifest.xml.
Get this from: keytool -list -v -keystore your-key.jks → copy the SHA-256 line. For debug: keytool -list -v -keystore ~/.android/debug.keystore -alias androiddebugkey -storepass android
⚠ Required server-side step: After downloading your ZIP, you must create this file on your web server at the exact URL shown above. The file must be served with Content-Type: application/json. Without this, Android App Links verification will fail.
